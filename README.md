# DPAIAI / DPI Pilot 0.5.0

Android-утилита локального обхода DPI без root с подбором стратегий для **YouTube и Instagram**.
Основана на ByeDPIAndroid (GPL-3.0), ByeDPI и hev-socks5-tunnel. Авторство и лицензии исходных компонентов сохранены: [UPSTREAM_README.md](UPSTREAM_README.md).

## Установка

Готовый APK находится в [GitHub Releases](https://github.com/Magral/DPAIAI/releases/latest).
Релизы подписываются постоянным ключом; начиная с 0.4.2 обновление устанавливается поверх предыдущего релиза.
Переход с прежней отладочной подписи требует однократной переустановки.

## Подбор для приложения

1. Выключите обработку DPI Pilot и другой VPN.
2. На главном экране нажмите «Подобрать для YouTube / Instagram».
3. Выберите сервис и запустите подбор. Проверяются контрольный режим и четыре стратегии.
4. Примените сохранённый результат: установленный стандартный клиент выбранного сервиса выберется автоматически.
5. Вернитесь на главный экран, включите обработку и проверьте приложение.

Для каждого сервиса сохраняется отдельный результат; одновременно действует одна стратегия.
Контрольный режим предпочтителен, если тоже проходит проверки. Иначе выбирается самый быстрый кандидат, прошедший все проверки в обоих раундах.
При неудаче старые настройки сохраняются. Уход с экрана останавливает подбор.
Каждый кандидат запускается в отдельном процессе :tuner, чтобы нативное состояние не переносилось между стратегиями.

YouTube: проверяются сайт, API и изображения. Instagram: сайт, API и CDN.
Проверка использует локальный SOCKS5 и проверяет TLS-сертификат и имя сервера.
Ответы 403/429 подтверждают достижимость сервера, а не доступ к контенту.
Видеопоток YouTube, QUIC, вход в Instagram, лента и Reels требуют отдельной проверки на телефоне.
Ошибки SOCKS/HTTPS с подробностями доступны через «Скопировать диагностику».

## Выбор приложений

В режиме VPN через движок идут только выбранные приложения. YouTube и Instagram показаны первыми; ниже доступны другие установленные клиенты.
Пустой выбор или удаление всех выбранных приложений не включает обработку всего телефона.
Ручной режим Proxy в расширенных настройках требует отдельной настройки клиента.

## Обновление с 0.4.x

Функциональность Telegram удалена: локальный MTProxy, WebSocket, открытие внешних прокси, подбор и native probes.
Прежние настройки и выбор Telegram очищаются. Если в Telegram остался прокси **127.0.0.1:1443**, отключите его в самом Telegram: DPI Pilot больше не обслуживает этот адрес.

**DPI Pilot TV** — отдельный APK для официального YouTube с пультом, автозагрузкой, автопроверкой и сменой стратегий. Описание и ограничения: [docs/ANDROID_TV.md](docs/ANDROID_TV.md).
