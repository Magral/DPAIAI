# DPAIAI / DPI Pilot

Android-утилита локального обхода DPI без root. Прототип 0.1.0.

Основана на ByeDPIAndroid (GPL-3.0), ByeDPI и hev-socks5-tunnel. Оригинальная документация: [UPSTREAM_README.md](UPSTREAM_README.md).

Добавлены локальные профили, пять экспериментальных режимов и проверка HTTPS через SOCKS с проверкой сертификата. Автоподбор и автоматическое переключение сетей пока не реализованы.

Подробности и сборка: [PILOT_README.md](PILOT_README.md). APK после успешной сборки доступен в Artifacts вкладки Actions. Это отладочная сборка; эффективность на конкретном провайдере требует проверки на устройстве.
