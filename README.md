# DPAIAI / DPI Pilot

Android-утилита локального обхода DPI без root. Прототип 0.2.0.

Основана на ByeDPIAndroid (GPL-3.0), ByeDPI и hev-socks5-tunnel. Оригинальная документация: [UPSTREAM_README.md](UPSTREAM_README.md).

Добавлены локальные профили, пять экспериментальных режимов и проверка HTTPS через SOCKS с проверкой сертификата. Добавлен экспериментальный подбор по сервисам; автоматическое переключение сетей пока не реализовано.

Подробности и сборка: [PILOT_README.md](PILOT_README.md). APK после успешной сборки доступен в Artifacts вкладки Actions. Это отладочная сборка; эффективность на конкретном провайдере требует проверки на устройстве.

## Выбор приложений
На главном экране нажмите «Выбрать приложения». YouTube, Instagram, Telegram и их известные варианты отображаются первыми, если установлены; ниже — другие приложения с иконкой запуска. Выберите одно или несколько и сохраните. При применении результата подбора установленный стандартный клиент выбранного сервиса выбирается автоматически. Затем включите обработку. Выбор сохраняется после перезапуска. Для изменения сначала выключите обработку.

В режиме VPN через движок идут только выбранные приложения. Пустой выбор или удаление всех выбранных приложений не включает обработку всего телефона. Ручной режим Proxy в расширенных настройках требует отдельной настройки клиента и не использует выбор приложений. Выбор приложения сам по себе не гарантирует обход блокировки по IP или работу звонков.

## Подбор для сервиса
На главном экране откройте «Подобрать для YouTube / Instagram / Telegram». Выберите сервис и запустите подбор при выключенной обработке. Контрольный режим и четыре стратегии запускаются по очереди в отдельном процессе :tuner на локальном порту 19080. После каждой проверки процесс уничтожается, поэтому C-состояние не переходит между кандидатами. Подбор останавливается при уходе с экрана и не меняет рабочие настройки до явного применения.

Списки адресов и порядок стратегий различаются. Каждый адрес проверяется дважды. YouTube: сайт, API, картинки; Instagram: сайт, API, CDN. HTTPS-проверки подтверждают сертификат и получение ответа (включая ошибки HTTP), но не доступ к контенту. Подписанные URL видеопотока googlevideo, QUIC, аккаунты, Reels и звонки не проверяются. Telegram: веб-адреса и начальный req_pq_multi/resPQ MTProto DC2 с проверкой nonce; без аккаунта, создания ключа и отправки сообщений. Это не аутентификация сервера. Адрес DC2 взят из официального Telegram Android ConnectionsManager.cpp; он может устареть или не совпасть с DC пользователя. Локальная стратегия не обходит полную блокировку IP.

Сохраняется только кандидат с успешными повторными проверками всех заданных точек, для Telegram обязательно включая MTProto. Если контроль тоже успешен, предпочтение отдаётся ему; иначе — самому быстрому из полностью успешных кандидатов. При полном или частичном провале прежний результат не меняется. Для каждого сервиса результат хранится отдельно, но движок применяет одну стратегию одновременно; персервисная маршрутизация стратегий ещё не реализована. Результат относится к текущей сети, без автоматической привязки к провайдеру.

Протокол проверки Telegram: https://core.telegram.org/mtproto/samples-auth_key и https://core.telegram.org/mtproto/mtproto-transports . Bootstrap IP: https://github.com/DrKLO/Telegram/blob/master/TMessagesProj/jni/tgnet/ConnectionsManager.cpp .
