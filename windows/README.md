# DPI Pilot YouTube для Windows 0.2.0

Windows-приложение и расширение для обычного Google Chrome. Отдельный профиль, специальный запуск браузера, системный VPN и сетевой драйвер не используются. Первый выпуск: Windows 10/11 x64, самостоятельный установщик EXE с включённой .NET 10.

## Установка

1. Запустите `DPI-Pilot-YouTube-Windows-0.2.0-Setup.exe`. Права администратора не нужны: установка для текущего пользователя.
2. В приложении нажмите «Установить расширение в Chrome». В своём обычном Chrome откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите установленную папку `extension`. Приложение копирует её путь. Распаковывать ZIP самостоятельно не нужно.
3. Нажмите «Включить обход» в приложении или расширении. После первого подбора открывайте YouTube как обычно в существующих вкладках. Вход в Google и текущий профиль Chrome сохраняются.

Одноразовое действие в Chrome обязательно: установщик не обходит защиту браузера и не добавляет расширение незаметно. Публикация в Chrome Web Store в этот выпуск не входит. Установленные файлы расширения не следует переносить или удалять; Chrome использует эту папку. Закрытие панели сворачивает приложение в трей, полный выход доступен в меню значка рядом с часами. Автозагрузка Windows включается по выбору пользователя; сохранённый включённый режим может также запустить компонент при открытии Chrome через Native Messaging.

## Граница действия

Расширение задаёт PAC только для обычных окон своего профиля Chrome (`regular_only`). Целевые домены: youtube.com, youtu.be, youtube-nocookie.com, googlevideo.com, ytimg.com и отдельные API/аватарные хосты YouTube. Общие google.com, accounts.google.com, googleapis.com и googleusercontent.com целиком не добавляются. Прочие URL получают DIRECT. Привязка выполняется по доменам, а не по названию вкладки: встроенное видео YouTube на другом сайте тоже относится к YouTube; любой ресурс на включённом CDN-домене идёт через обработчик. Incognito, другие профили и браузеры отдельно не настраиваются.

Windows-компонент дополнительно проверяет каждое SOCKS5-соединение: только разрешённое доменное имя, TCP CONNECT, порт 443. IP-адреса вместо имени, посторонние домены, UDP ASSOCIATE и BIND отклоняются. Оба TCP-слушателя привязаны к 127.0.0.1. HTTPS не расшифровывается, сертификаты не подменяются, корневой сертификат не устанавливается. Chrome выполняет обычную проверку TLS. Сам компонент не читает страницы, аккаунт, cookie и историю браузера.

Системные proxy/WinHTTP, DNS, маршруты и firewall не записываются. Нет перехвата всех пакетов, WinDivert или отключения UDP/QUIC на компьютере. Игры, лаунчеры и прочие приложения не получают этой настройки прокси. Как у любой сетевой программы, диагностические запросы и просмотр используют ресурсы компьютера/канала; обещание нулевой нагрузки или неизменного пинга при насыщении канала не даётся.

Чтобы не менять маршрутизацию чужих сайтов, расширение отказывается перезаписывать уже действующие Chrome-прокси/политики/другое прокси-расширение. Компонент читает исходную конфигурацию WinINet и проверяет отсутствие WPAD. При обнаружении явного системного прокси/PAC/WPAD либо неизвестном результате проверки включение правила блокируется с сообщением. Существующие конфигурации не удаляются. Этот выпуск рассчитан на исходное прямое соединение, а не на совмещение с корпоративными PAC.

## Автоматика и данные

Используется закреплённый ByeDPI 17.3 `ba532298de7b28cfe854aea83d061369d13ca290`, собираемый из исходников, а не сторонний скачанный EXE. Параметры Linux-only md5sig/drop-sack и TFO исключаются. Каждый оставшийся вариант запускается с проверкой SOCKS5 в CI на Windows. Это доказывает совместимость команды с движком, но не эффективность у каждого провайдера.

Встроена настоящая подписанная база канала проекта. Публичный сертификат извлекается из закреплённого по SHA-256 публичного Android APK и сверяется с постоянным отпечатком; приватный ключ Windows-сборке не нужен. Ежедневная проверка обновлений, ограничения размера/команд, точный commit движка, RSA/SHA-256 подпись, защита от отката, атомарное сохранение и офлайн-база действуют отдельно от обновлений EXE. Новые исполняемые файлы через канал стратегий не загружаются. Отсутствие доступа к GitHub не останавливает сохранённую стратегию.

Текущая стратегия проверяется раз в пять минут. При отказе/устойчивом дефиците ответов проверяется ограниченный фоновый блок вариантов; сохранённые успешные ID остаются в приоритете. Кандидаты имеют отдельные процессы и порты. Существующие TCP-потоки удерживают свой процесс, пока не завершатся. После смены наблюдаются новые соединения и возможен откат к прежнему рабочему варианту. Проверки generate_204, превью и TLS к CDN не выдаются за доказательство воспроизведения каждого видео. Ненадёжный тест прямых публичных видеофрагментов не используется.

При отключении расширение освобождает своё значение Chrome proxy; при потере связи освобождение происходит после уведомления/проверки состояния (обычно до 10 секунд). Если браузер остановил расширение, возможна задержка до его возобновления. Настройки Windows при этом не требуют восстановления. Остановка через приложение закрывает только его YouTube-соединения; чужие TCP-потоки не закрываются. Нативные дочерние процессы входят в отдельный Windows Job с kill-on-close. Chrome и игры в этот Job не включаются.

## Проверки и ограничения первого выпуска

CI проверяет подпись настоящей базы/подмену/откат/пределы параметров, запуск каждой совместимой команды на настоящем Windows EXE, сохранение постороннего непрерывного TCP-потока и активного проксируемого потока при старте/остановке тестовых движков. Настоящий Google Chrome проверяет PAC: YouTube обращается к loopback-обработчику, посторонний тестовый сайт остаётся DIRECT. JS-тесты проверяют доменные границы, конфликты прокси и освобождение ChromeSetting. Полная проверка просмотра, Chrome-политик и поведения конкретного антивируса выполняется на пользовательском ПК.

Установщик пока не подписан доверенным Authenticode-сертификатом издателя. Подпись базы стратегий — отдельная проверка подлинности данных, не замена подписи EXE. Код приложения GPL-3.0, закреплённый нативный движок MIT; уведомление движка включено в установку.

## Выбор стратегий в 0.2.0

В меню «Годные стратегии» показаны полные результаты 6/6 для текущего профиля сети, задержка HTTPS и время проверки. Свежий результат применяется без сетевого повторения в течение 72 часов; устаревший проверяется перед сменой маршрута. Частичные результаты не допускаются. Временный сбой не удаляет прежний полный результат.

«Подобрать стратегии» сравнивает ограниченный блок и свежие результаты; «Перепроверить» принудительно обновляет доказательства. Автоматический периодический подбор выключен по умолчанию; если включён, интервал — 72 часа с сохранением времени попытки между перезапусками. Счётчики соединений не запускают тесты. История выбранных маршрутов сохраняется отдельно для сети. Сброс исключений доступен из меню стратегий.

Новых настроек DNS в Windows 0.2.0 нет: системные DNS, proxy, маршруты и настройки игр не меняются. Подпись каталога проверяется; установщик EXE не имеет доверенной подписи Authenticode.

Ограничение идентификации сети: профиль определяется доступными параметрами интерфейса/шлюза и DNS, без SSID. Две физически разные сети с одинаковыми параметрами могут иметь общий профиль; после такого переключения используйте принудительную перепроверку. Кэш изолирован между различающимися профилями, но это не гарантирует уникальность физической сети.
