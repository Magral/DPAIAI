# TV 0.6.0: обновляемая база стратегий

Ежедневный сбор: `.github/workflows/strategy-catalog.yml`, 03:23 UTC (GitHub может задержать запуск). Сборщик читает фиксированный список известных источников из `tv/strategies/sources.json`: четыре GitHub-коллекции, закреплённую документацию движка, публичные страницы форумов, сайты и инструкции. Это обновление известных источников, не автоматический поиск по всему интернету. Новые сайты добавляются изменением проверяемого списка в репозитории. Сбоев загрузки отдельных сайтов ожидаем: отчёт сохраняет состояние и SHA-256 полученного текста. Отсутствующие источники не стирают предыдущие команды; если ни один источник не дал команд, новая публикация не создаётся.

Извлекается только текст команд. Строгий список параметров запрещает изменение адреса/порта локального прокси, чтение внешних файлов и запуск команд. Алиасы нормализуются, повторения объединяются по SHA-256 команды, параметры памяти/повторов/задержек ограничены. Каждый вариант, включая сохранённые, запускается на закреплённом ByeDPI 17.3 с проверкой SOCKS5 и отдельной неизменной группой DNS. Результат доказывает совместимость команды с движком; пригодность для конкретной сети проверяет приставка. Максимум 2000 вариантов, полезная нагрузка до 2 МиБ.

Публикация: независимый релиз `strategy-catalog`, файл `catalog-v1.json`. Конверт содержит Base64 полезной нагрузки и подписи RSA/SHA-256. Подпись покрывает префикс `DPI-PILOT-TV-CATALOG-v1\n` и точные байты JSON. Постоянный ключ APK восстанавливается только на CI, сертификат сверяется с закреплённым отпечатком; временный PKCS12 удаляется. Приватный ключ не публикуется. `refresh-report.json` содержит сводку источников и отклонённые строки; данные и полный отчёт дополнительно хранятся в артефактах Actions 30 дней. Канал данных не назначается последним релизом телефонного приложения.

На приставке проверяются HTTPS, ограниченный список доменов перенаправления GitHub, размер ответа, подпись закреплённого сертификата приложения, схема, точный commit движка, монотонный номер публикации, идентификаторы команд, параметры и размеры списка. Повторный номер должен соответствовать сохранённому хешу конверта. Debug APK с другим сертификатом получает только встроенную базу. Выполняемые файлы, APK, нативные библиотеки и скрипты через этот канал не доставляются.

Проверка выполняется в отдельном IO-потоке при работе VPN-службы: после запуска, если прошло 24 часа с успешной проверки; после ошибки не чаще раза в час. Таймер пробуждается раз в 15 минут, сон Android может задержать проверку. Кнопка «Обновить базу стратегий» запускает проверку вручную, даже если VPN выключен. Последние попытка/успех/загрузка, версия и состояние видны в приложении и полном отчёте. При выключенной приставке запросов нет. Доступ к GitHub необходим только для получения новых данных; недоступность GitHub не останавливает VPN.

Подписанный конверт сохраняется через AtomicFile. После перезапуска он снова проверяется. При ошибке сети или подписи работа продолжается на текущей базе; повреждённый кеш оставляет встроенные 279 вариантов. Восстановление актуального подписанного кеша возможно последующей загрузкой. Номера вариантов внутри процесса только дополняются, поэтому обновление не меняет идентичность уже проверяемого кандидата. История и сохранённый рабочий вариант привязаны к стабильным ID. Процесс движка получает конкретную проверенную команду через закрытый IPC, а не индекс другой копии базы.

Загрузка базы не переключает стратегию и не пересоздаёт VPN. Новые кандидаты становятся доступны существующему ограниченному фоновому подбору с проверкой качества и откатом; сохранённые успешные варианты остаются в приоритете. Автоматический подбор не проверяет все 2000 команд одновременно. Для смены движка понадобится новый APK и отдельная совместимая версия канала. В будущем небезопасный вариант удаляется обновлением приложения/политики; канал намеренно сохраняет прежние варианты и не является дистанционной командой их принудительно включить.

Проверки: тесты подписи/подмены/чужого ключа/отката/совместимости/размеров, фильтра команд, индексов после добавления, источников и ограничений ресурсов; существующий полный набор TV-тестов и постоянной подписи. Холодный старт и многосуточный просмотр на физической X96 проверяются владельцем устройства, не имитируются CI.
