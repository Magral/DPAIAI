# DPI Pilot Android 0.11.0

- Быстрый первый проход без подтверждающих повторов: ожидание ответа ограничено 5 секундами, общий срок одного сетевого запроса — 8 секундами. Все обязательные тесты сохраняются: YouTube 8/8, Instagram 6/6.
- Медленные и неудачные кандидаты откладываются для отдельного полного прохода. Таймаут и общий сбой сети не приводят к постоянным исключениям. Частичные результаты разных попыток не складываются.
- Первая полностью годная стратегия применяется сразу. Далее подбор продолжается, затем выбирается годная с минимальной задержкой. При применении свежего результата полный тест не повторяется.
- Общий счётчик «проверено / всего / осталось», полоса прогресса и отдельное число отложенных вариантов для каждого сервиса. Отдельные статусы «Уже работает» и «Ищем более быструю».
- Кнопки открытия установленных YouTube и Instagram, включая Instagram Lite. Для запуска клиента не требуется включать подбор.
- Отдельный раздел «Генератор стратегий»: ручной запуск для выбранного сервиса, лимит 2/5/10 минут, остановка, сохранение полных результатов отдельно для каждой сети. До 120 уникальных кандидатов за запуск. Первая годная применяется сразу; найденные варианты доступны для ручного применения.
- Генератор меняет поддерживаемые параметры разделения, порядка отправки, TLS-записей и TTL в известных формах. Кандидаты проходят строгий парсер, запуск изолированного нативного процесса и полный сетевой тест. Совместимость запуска не означает работоспособность у провайдера.
- База содержит 288 встроенных стратегий: 9 новых уникальных вариантов после нормализации и проверки запуска. Расширены источники: отобранные конфигурации CherretGit, операторские пресеты BarisKeser, обсуждение ByeDPIAndroid и пример B-Checker. Дубли удаляются; неподдерживаемые параметры не включаются в базу. Windows-скрипты и сторонний код генераторов не исполняются.

Установка поверх 0.10.1 с прежней постоянной подписью. ТВ-приложение отдельно не выпускается; база стратегий общая. Проверка входа, ленты и воспроизведения в реальных приложениях на телефоне остаётся необходимой.
