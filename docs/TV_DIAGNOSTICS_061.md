# TV 0.6.1: диагностика без ненадёжного медиатеста

Предыдущий тест открывал страницу одного публичного ролика, искал прямой URL в `ytInitialPlayerResponse`, затем дважды запрашивал первые 128 КиБ. Если прямая ссылка отсутствовала, требовалась авторизация, возвращался отказ либо менялся формат страницы, результат оставался недоступным. На приставке пользователя при этом обычный YouTube работал. По имеющимся сообщениям нельзя установить конкретный HTTP-ответ, но зависимость от выдачи прямого URL видна в коде. Надёжность отдельной проверки видео таким способом не доказана.

В 0.6.1 этот путь удалён: классы MediaProbe/MediaLinks/ProbeBudget/ProbeHttp, запрос watch-страницы, загрузки видеообразцов, состояние «медиадоставка не подтверждена», скорость/повторяемость образца в ранжировании и истории. Это функциональное удаление, не смена текста. Медиатест больше не может отвергнуть стратегию или вызвать её замену. Старые поля `kbps` в истории игнорируются; сохранённые ID стратегий и остальные показатели истории сохраняются. Лимит медиадиагностики больше не нужен, поскольку этих запросов нет.

Сохраняются два раунда трёх проверок: YouTube generate_204, до 1024 байт превью i.ytimg.com, проверенный TLS к redirector.googlevideo.com. TLS к CDN означает только доступность узла. Для HTTP применяется ограниченный парсер: обрыв тела до требуемого объёма, противоречивые Content-Length/Transfer-Encoding и некорректные chunks отклоняются. У превью дополнительно проверяются сигнатура JPEG/PNG/WebP, MIME и минимальная длина; HTML под видом изображения не засчитывается. Статус при успехе: «VPN включён · проверки YouTube пройдены».

Для выбора без наблюдаемого полезного потока остаётся значительное улучшение задержки контрольных проверок; при неисправной текущей стратегии — кандидат, прошедший проверки. Не делается вывод о скорости текущего ролика. Подбор не отключает активный туннель. Защита полезного потока, счётчики реального трафика YouTube, устойчивая исходящая активность с дефицитом ответов, паузы/сон/потеря сети, пробная смена до двух минут и откат работают как прежде. Число успешных контрольных тестов, полезный обмен, зависания и откаты участвуют в истории качества. Наличие трафика не выдаётся за наблюдение картинки или звука.

Автозапуск, включение/выключение, подписанная обновляемая база, источник/версия базы, отчёты и постоянная подпись APK сохранены. Юзерский видеоплеер и аккаунт не читаются. Успешная диагностика сети не гарантирует воспроизведение каждого ролика. Проверки на физической X96 выполняет владелец; CI проверяет программную логику, нативные компоненты и выпуск.
