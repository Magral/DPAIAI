# DPI Pilot TV 0.6.3

На основном экране добавлена кнопка «Выбрать найденную стратегию». Список содержит успешные проверки и сохранённые рабочие варианты текущего профиля сети, включая запасные варианты, проверенные в scout-процессе, но не применённые. Результаты сохраняются после перезапуска. Частичный тест не добавляет новый вариант в список.

Показываются номер, текущий статус, успехи/отказы, задержка, полезный обмен и откаты. Номер служит обозначением в текущей базе: сохранение и применение используют стабильный ID команды. Удалённый ID не превращается в другую стратегию с тем же номером. После обновления базы недоступные варианты скрываются.

Выберите строку, просмотрите команду и источник, нажмите «Проверить и применить» при включённом VPN. Проверка выполняется отдельно от текущего туннеля; отказ оставляет прежний вариант. Успешный тест запускает выбранную команду и существующее испытание до двух минут с откатом к работавшему резерву при подтверждённом ухудшении. Смена туннеля может переподключить видео. Более новый ручной запрос отменяет применение прежнего ожидающего запроса.

Подтверждённый ручной выбор имеет приоритет при следующем запуске в этой сети. Это не вечная блокировка: при реальном отказе остаются обычные резервы и восстановление. Переключение в другую сеть не применяет незавершённый запрос старой сети.

Тихий режим сохранён: открытие списка ничего не тестирует, периодический контроль автоматически не включается, обновление базы не меняет рабочую стратегию. Установить подписанный APK поверх ТВ-версии.
