# DPI Pilot mobile 0.6.1

Исправление задержки подбора и пустой диагностики в мобильной версии.

- Процесс проверки передаёт текущий этап, узел и раунд через отдельные сообщения Messenger. Сообщение прогресса не завершает ожидание итогового результата.
- Экран показывает запуск движка, локальный SOCKS5, DNS/TCP, TLS, HTTP и счётчик ожидания. Ошибки запуска и завершения процесса содержат описание.
- Каждый узел имеет жёсткий общий срок: тайм-аут стратегии + 3 секунды. Таймер закрывает сокет, включая чтение с медленным поступлением байтов. Общий сетевой бюджет стратегии — 180 секунд; внешний лимит процесса — 205 секунд, отдельно от очистки процесса. Адаптивные стратегии сохраняют увеличенные сроки.
- Неудачный узел не опрашивается повторно во втором раунде. Пропуск явно записывается как неуспешная проверка и не уменьшает знаменатель; критерий полного прохождения не ослаблен.
- Копирование диагностики включает текущий экран, текущий этап, журнал с временем, завершённые результаты и отдельно фоновый контроль VPN. Журнал сохраняется между открытиями экрана; после старта нового блока начинается заново.
- Экран не засыпает во время ручного подбора. Уход с экрана отменяет ручной подбор с записью причины. Остановленный подбор не сохраняет непроверенный вариант.

Проверки: unit-тесты позднего подключения после истечения срока и реального молчащего SOCKS-сервера, закрываемого по общему сроку; существующие тесты каталога, подписи и JNI; проверка подписи и содержимого APK в CI.

Работоспособность Instagram/YouTube на конкретном операторе требует проверки на устройстве. Исправление предотвращает неограниченное ожидание сетевых операций и даёт диагностические данные; оно не гарантирует прохождение блокировок.
