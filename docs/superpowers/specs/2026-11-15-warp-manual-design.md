# Manual free WARP transport — phone first

User confirmed real YouTube menu/video/Shorts work through Nova WARP, rejected paid VPN integration. Approved sequence: manual WARP in phone DPI Pilot, fixed YouTube+Instagram routing, preserved local strategies; automatic fallback and TV follow after actual device acceptance. WARP is a third-party free Cloudflare service, no availability guarantee.

Implementation choice: small own Android VpnService and source-built pinned AmneziaWG Go engine (MIT), not Nova's complete multi-protocol service or opaque AAR. No Nova relay credentials, shared private keys, paid services, third-party proxy lists or server scans. Generate fresh X25519 key on device and register it with Cloudflare over strict HTTPS after explicit setup action. Registration may fail on blocked API; setup can use an already-working external WARP temporarily with DPI Pilot included. Once saved, standalone WARP doesn't require Nova. Never erase saved identity on network failure. Optional exact WireGuard/AWG import allows using a user's own exported profile; no command execution or filesystem directives.

UI: transport settings button on main screen, choice local/WARP only while stopped, setup/register, status/details, native handshake/byte counters, start/stop through existing app controls. WARP requires Android7+ (API24 guard) while local mode retains minSdk21. Only installed fixed YouTube+Instagram packages may enter TUN; zero packages fails before establish, never falls back to full-device routing. IPv4 and IPv6 inside TUN, protected IPv4 outer UDP, MTU1280, DNS1.1.1.1 inside selected-app tunnel. No system DNS/proxy edits, no bypass of TLS certificate checks.

Store config AES/GCM under AndroidKeyStore in noBackupFilesDir, never in logs/profile export/public report/catalog. Per-process serial lifecycle, cancellation during startup prevents late activation, stop/revoke/network change closes native TUN and sockets, reconnect only on physical network change, bounded attempts on start, no continuous strategy scans. Show interface creation separately from authenticated handshake. Mode defaults local; app update never switches silently. WARP diagnostics use safe counters only; old local SOCKS diagnostics/tuning disabled in WARP mode.

Native interface owns a dup of TUN fd, calls VpnService.protect before every outer socket use, closes all resources on error. Build4ABIs from pinned Go module with go.sum, NDK; no downloaded executable inside release APK. Test public-key/config validation, fixed package allowlist, stale/cancelled generations, protected-bind failures, reserved bytes, key redaction, setup bounds. Required signed Android CI and APK audit before manual experimental release0.13.0. Actual network acceptance remains user-device gate, not CI success. TV/Windows unchanged until manual phone acceptance.
