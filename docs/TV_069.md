# DPI Pilot TV 0.6.9

После исправления строгих порогов превью в 0.6.8 добавлено подтверждение отказа перед постоянным исключением. Если ранее прошедшая 6/6 стратегия дала отказ, либо неизвестная стратегия ответила частично (1–5 проверок), выполняется ровно один повтор после 750 мс. Неизвестный вариант без успешных ответов отбрасывается сразу. Допуск остаётся строгим: все шесть проверок должны пройти в одной попытке. Результаты частичных попыток не складываются.

Подтверждающий повтор проверяет только обязательные узлы; дополнительные полные превью заново не скачиваются. Успешная первая попытка не повторяется. Отсутствующий тестовый источник не вызывает повтор и исключение. Перед повтором проверяются смена сети, выключение VPN и ручные запросы. При прерванном тесте основная служба сохраняет существующие проверки отмены перед записью исключений.

Испытание новой стратегии использует это же подтверждение: отдельная вложенная серия повторов удалена. При подтверждённом отказе сохраняется откат на предыдущую рабочую стратегию. Отметка повторной попытки отображается в журнале и результате проверки.

Период автоматического подбора остаётся 72 часа; постоянного сетевого мониторинга не добавлено. Исключения и ручные жалобы не сбрасываются этим обновлением. Миграция ошибочных автоматических исключений 0.6.7, исправленная в 0.6.8, сохранена и выполняется только один раз.

Тесты проверяют условия единственного повтора, быстрый отказ неизвестных нулевых вариантов, отсутствие допуска по двум частичным результатам, строгий допуск 6/6 и сохранённые политики расписания/качества. APK подписан прежним постоянным ключом. Тесты CI не заменяют проверку на пользовательской приставке.
