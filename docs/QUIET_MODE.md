# Тихий режим: телефон 0.8.0, ТВ 0.6.2, Windows 0.1.1

Рабочая стратегия должна сохраняться без регулярного сетевого тестирования и поиска более выгодного варианта. Это основной режим всех трёх приложений.

| Событие | Поведение |
|---|---|
| Запуск/перезагрузка с ранее включённым обходом | Запуск сохранённого обработчика и стартовая проверка |
| Успешная проверка | Ожидание события; нет планового опроса сервисов |
| Изменение физической сети | Проверка доступности в новой сети |
| Ручная команда проверки/«не работает» | Проверка и, при необходимости, расширенный подбор |
| Аварийное завершение обработчика | Восстановление и проверка |
| Обновление базы | Сохранение новых данных; рабочая стратегия не меняется |
| Периодический режим включён отдельно | Дополнительные проверки примерно раз в час |

Автоматический стартовый перебор ограничен небольшим блоком; постоянного перебора по всей базе нет. Ручной расширенный подбор остаётся доступным. Испытание фактически переключённой новой стратегии ограничено примерно двумя минутами и не является постоянным наблюдением.

На ТВ открытие окна программы или YouTube не запускает повторную сетевую проверку работающей службы. Крупный основной экран содержит включение VPN, запуск YouTube и краткое состояние; подробности и настройки скрыты за дополнительной кнопкой. Системный watchdog следит за жизнью службы и не опрашивает YouTube каждые 15 минут.

На смартфоне включены только поддерживаемые клиенты Instagram/YouTube, без выбора приложений/целей. Обработчики независимы, переключение одного не перезапускает второй. Подробности: MOBILE_080.md.

На Windows сохраняется схема Chrome extension + локальный YouTube-only gateway, без изменения системных proxy/DNS/маршрутов. При обновлении используется прежняя папка расширения. Дополнительное наблюдение трафика выключено вне испытания, если пользователь не включил периодический режим. Расширение продолжает локальный обмен состоянием с помощником — это не запросы к серверам YouTube.

Автозагрузка/восстановление не отменяют ручное выключение. Android может ограничить фоновый запуск; Windows запускается при входе пользователя, если включён автозапуск. Успешные пробы публичных узлов не гарантируют воспроизведение любого ролика.

Обновление базы — отдельная автоматизация: ежедневный сбор известных источников, нормализация и native-проверка команд, подпись, загрузка приложением с проверкой подписи и защитой от отката. Новые источники раз в неделю предлагаются отдельным отчётом; сначала требуется проверка источника и прохождение обычного фильтра, а не немедленная активация произвольных команд.
