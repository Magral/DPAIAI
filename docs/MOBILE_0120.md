# DPI Pilot Android 0.12.0

- На главном экране компактные кнопки открытия YouTube и Instagram с настоящими значками установленных приложений (включая Lite).
- Годные стратегии отсортированы по измеренной задержке HTTPS. Для каждой показаны миллисекунды, полный результат, DNS и дата проверки. Задержка не является ICMP ping.
- Результаты успешных проверок хранятся отдельно для каждой сети и сервиса и повторно используются 72 часа. Обычный подбор не повторяет свежие успешные тесты. Есть отдельная принудительная перепроверка. Временный сбой не стирает успешное доказательство; жалоба пользователя исключает вариант. Повторное использование не продлевает срок свежести.
- Запуск сохраняет применённую стратегию, если пользователь не исключил её. Обновление базы и истечение срока проверки не сбрасывают работающий маршрут.
- DNS: автоматический подбор, DNS сети и ручной IPv4/HTTPS DoH. База включает Cloudflare, Google, AdGuard без фильтрации, Quad9 без фильтрации, Control D без фильтрации, DNS.SB, DNS4EU без фильтрации и Яндекс базовый. Источники опубликованы в настройках. Доступность проверяется в сети устройства; это не перечень всех DNS в мире.
- Проверка DNS охватывает API и CDN целевого сервиса; далее испытываются до трёх DNS вместе со стратегией. Для YouTube и Instagram сохраняются независимые DNS. Выбранный DNS используется и тестовыми соединениями, и реальными TCP-подключениями с распознанным Host/SNI. Системный DNS Android не меняется. UDP DNS имеет TCP-резерв, DoH проверяет HTTPS-сертификаты. Кэш A-ответов ограничен TTL/300 секундами и очищается при смене сети.
- YouTube: 13 адресов из списка ByeByeDPI в двух раундах (26/26), действительный JPEG-превью и публичные видеодиапазоны до 256 КБ на запрос, до двух запросов. Проверяются ответ, тип, объём и минимальная скорость 512 Кбит/с. Это ограниченная выборка, не гарантия конкретного разрешения или каждого Shorts.
- Если YouTube не выдаёт публичную ссылку (consent, вход, подпись проигрывателя, истёкший адрес), проверка не завершена. Такой вариант не попадает в полностью годные; существующий маршрут продолжает работать. Общий сбой не создаёт массовых исключений. Тест не входит в аккаунт и не расшифровывает трафик клиента.
- Сохранено исправление 0.11.1: независимые ограниченные пулы отправки, загрузки и DNS/UDP для устранения обрывов при множестве одновременных соединений.

Автоподбор — не чаще одного раза в три дня, ручной — по запросу. Новые проверки не являются постоянным фоновым наблюдением. Работа приложений в конкретной сети требует проверки установленного APK.
