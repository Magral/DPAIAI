# DPI Pilot Android 0.12.1

Исправление регрессии 0.12.0 в подборе и DNS-маршрутизации.

- YouTube: 13 адресов за один проход. Повтор по тем же адресам не удваивает обычный счётчик. Сначала проверяются все четыре основные точки: www.youtube.com/generate_204, настоящий JPEG-превью, API youtubei.googleapis.com и redirector.googlevideo.com. Для сетевой годности нужны строго 4/4; результат 3/4 не допускается. Остальные 9 адресов показаны как вспомогательная диагностика и не отменяют успешный основной тест.
- Убрана остановка всех запросов после первой ошибки. Все основные запросы завершаются независимо. Если основные не пройдены, вспомогательные пропускаются явно; после успешных основных завершаются все дополнительные запросы. Счётчики разделяют выполненные и успешные проверки.
- Возвращён канонический www.youtube.com для generate_204. Корневой youtube.com в 0.12.0 мог давать переадресацию, ошибочно принятую за неуспех.
- Анонимный медиатест перенесён из обязательного теста каждого кандидата в отдельную оценку качества после выбора. Отсутствие публичной ссылки/требование входа/истечение URL не исключает рабочую стратегию. Успешный сетевой тест не выдаётся за подтверждённое воспроизведение.
- Готовые числовые IP приложений сохраняются без повторного DNS-разрешения по SNI. Это предотвращает незапрошенную замену выбранного приложением CDN-сервера. DNS продолжает работать для DNS-запросов приложений и для доменных SOCKS-запросов; системный режим не делает лишний DNS-запрос на каждом подключении.
- В автоматическом DNS-режиме ошибка выбранного DNS допускает резервный запрос к DNS сети. Ручной DNS не получает скрытого резерва. Новый подбор не сохраняет недоступный DNS первым кандидатом только потому, что он был применён ранее.
- Рабочие результаты хранятся по доказательствам основных проверок, а не по старому числу 26. Подтверждённые старые результаты с теми же основными точками можно повторно использовать. Новая частичная/временная неудача не стирает ранее успешный результат и не отключает работающий маршрут. Жалобы пользователя сохраняются.
- Задержка для сортировки рассчитывается по успешным основным запросам, без таймаутов вспомогательных адресов. Для Instagram сохранены все 6 обязательных проверок.

Сохранены подпись приложения, настройки, кэш на 72 часа, отдельные стратегии YouTube/Instagram и редкий автоподбор. Проверки сборки и протокола не заменяют испытание установленного APK в сети устройства.
