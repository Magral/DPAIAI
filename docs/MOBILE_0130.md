# DPI Pilot 0.13.0 — ручной бесплатный WARP

Добавлен отдельный экспериментальный режим WARP для YouTube и Instagram. Основная кнопка запуска/остановки и уведомление управляют выбранным режимом. Остальные приложения не включаются в туннель. Локальный обход и его сохранённые стратегии остаются доступны, режим после обновления сам не меняется.

Настройка: выключить DPI Pilot → «Режим подключения» → выбрать бесплатный WARP → создать собственное подключение Cloudflare. Если регистрация в сети блокируется, один раз включить уже рабочий WARP в Nova, добавить DPI Pilot в приложения его туннеля и повторить создание. После сохранения отключить Nova и включить WARP в DPI Pilot. Также доступен импорт собственного текстового WARP/WireGuard/AWG профиля .conf с IPv4-сервером Cloudflare. Это не импорт базы общих чужих ключей.

Ключ создаётся на устройстве, сохраняется с AES/GCM в AndroidKeyStore/noBackupFilesDir и не попадает в экспорт стратегий/статус. Платная подписка, ключ WARP+ и сторонние прокси не требуются. Условия Cloudflare доступны перед явным созданием подключения. Встроенные аккаунты и релей Nova не используются.

Ядро AmneziaWG закреплено на v3.1.20260828 и собирается из исходников для четырёх ABI. Туннель направляет только установленные поддерживаемые приложения; пустой список останавливает запуск. Внешние сокеты привязываются к физической сети и защищаются от петли в собственный VPN. IPv4/IPv6 внутри туннеля, MTU1280, DNS1.1.1.1 только внутри VPN выбранных приложений. Системные DNS/прокси не меняются.

При старте выполняется ограниченный подбор портов/вариантов WARP, после соединения — только пассивные счётчики. Повторное подключение при смене физической сети; постоянных проверок стратегий нет. Ключ не удаляется из-за таймаута. Остановка/отзыв VPN закрывают соединение. Подбор локальных стратегий и локальная SOCKS-диагностика в режиме WARP отключены, чтобы не создавать ложных результатов.

Требуется Android7+ для WARP; локальный режим сохраняет поддержку Android5+. Статус рукопожатия и счётчики не подтверждают проигрывание всех видео. Успешный пользовательский контроль относился к Nova WARP; самостоятельный DPI Pilot требует отдельной проверки меню, видео и Shorts после установки. Автоматическое переключение локальный→WARP, ТВ и Windows в этом выпуске не менялись: они следуют после подтверждения смартфонного режима.

APK подписан прежним постоянным ключом и устанавливается поверх предыдущей версии.
