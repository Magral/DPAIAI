# DPI Pilot TV 0.1.0

Отдельное приложение: `io.github.magral.dpipilot.tv`. Устанавливается рядом с телефонной версией. Android 5+; APK содержит ARMv7, ARM64, x86 и x86_64. Только официальные пакеты YouTube: `com.google.android.youtube.tv` и `com.google.android.youtube`.

## Первое включение

Установите APK, один раз откройте приложение и нажмите «Включить авторежим». Подтвердите системное разрешение VPN. Фокус кнопок выделен рамкой; управление стрелками и OK, мышь не нужна.

Автозапуск при загрузке ТВ включён по умолчанию после разрешения VPN. Если прошивка предоставляет системный пункт «Постоянный VPN», включите его для DPI Pilot TV. **Не включайте блокировку соединений без VPN**: маршрутизация рассчитана только на YouTube, остальные приложения работают напрямую.

Первый запуск после установки обязателен. Принудительная остановка приложения в настройках Android и ограничения производителя могут блокировать автозапуск. Разрешение VPN нельзя подтвердить без пользователя. Некоторые телевизоры скрывают настройки постоянного VPN; в таком случае используется BOOT_COMPLETED. Изменения прошивки/энергосбережжения проверяются на самом телевизоре.

## Автоматический цикл

- При запуске службы, открытии DPI Pilot TV, включении экрана, изменении физической сети и каждые 5 минут выполняется проверка.
- Сохранённая стратегия проверяется первой. При повторной неудаче последовательно тестируются альтернативы; одновременно работает только один движок.
- Положительный результат: два раунда — ответ YouTube generate_204, часть изображения с корректным content-type и TLS к redirector.googlevideo.com. 403/429, HTML-заглушки и пустое изображение не считаются успехом.
- Проверенные параметры сохраняются только после успешного создания VPN. При общей недоступности сети старый результат не перезаписывается; прежняя стратегия восстанавливается по возможности. Повторные попытки: через 1, 2, 5, затем 10 минут.
- Полный транспорт видеоролика и скорость воспроизведения не проверяются: TLS googlevideo проверяет доступность узла, а не доставку конкретного видео. Для ручной смены при зависшем видео есть «Подобрать другую стратегию».

## Маршрутизация и изоляция

В allowlist только установленные официальные клиенты YouTube. Пустой allowlist не устанавливается. Только UDP/443 для этих клиентов отклоняется TV-сборкой движка, чтобы YouTube использовал TCP. DNS/UDP и TCP/443 сохраняются; отдельный C-тест проверяет это для IPv4 и IPv6. DNS берётся из физической сети телевизора. Остальные приложения и исходящие соединения самой утилиты не идут в TUN. IPv6 не включается в VPN-конфигурацию; отдельный IPv6-обход не заявлен.

Каждый экземпляр ByeDPI запускается в отдельном процессе :engine. Перед сменой стратегии VPN закрывается, привязка к процессу снимается и ожидается его завершение; C globals не переиспользуются. Служба VPN сразу показывает постоянное уведомление, сохраняет выбор, поддерживает START_STICKY и системный запуск always-on. При отзыве разрешения останавливается. Автоматический запуск YouTube поверх других приложений не выполняется.

## Сборка и подпись

`bash gradlew :tv:assembleRelease :tv:testReleaseUnitTest`

Ключ тот же постоянный ключ проекта. Условия выпуска — docs/SIGNING.md. CI сверяет сертификат, запускает тесты порядка fallback, ограничений health checks и отдельный нативный тест выборочного запрета QUIC. Телефонный APK не заменяется. TV-релизы имеют теги tv-vX.Y.Z и не меняют latest телефонного приложения.

Документация Android: https://developer.android.com/develop/connectivity/vpn
https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start

Первый релиз требует проверки на реальном телевизоре: пульт, выключение/включение, смена сети, холодная загрузка, отзыв VPN и воспроизведение YouTube. Проверка сборки и JVM-тестов не заменяет эти испытания.
