# DPI Pilot Android 0.11.1

Исправлена конкуренция за потоки в локальном прокси: загрузка и отправка данных теперь имеют независимые ограниченные пулы, DNS-запросы вынесены отдельно. Раньше при большом числе соединений обработчики занимали общий пул и отправка нового потока отклонялась, закрывая соединение.

Нагрузочный тест держит 104 соединения с адресом видеодоставки и проверяет повторный обмен на каждом. На старом коде тест воспроизводит обрыв; на исправленном проходит. Дополнительно проверяются переключение стратегий без разрыва существующих соединений, TLS SNI и DNS/UDP.

Это исправление подтверждённого дефекта под нагрузкой; воспроизведение Shorts на конкретной сети требует проверки установленного APK. Сетевые тесты подбора по-прежнему не подтверждают реальную видеодоставку. Доработки интерфейса, DNS-подбора и расширенной проверки видео остаются отдельным этапом.
