# DPI Pilot Android 0.10.1

- Отдельные переключатели подбора YouTube и Instagram. Отключённые приложения не проверяются; отключение во время подбора прерывает их текущую проверку. Можно выключить оба. Выбор сохраняется после перезапуска; сохранённые маршруты остаются.
- Первая стратегия, прошедшая полный тест (YouTube 8/8, Instagram 6/6), применяется сразу. Остальные стратегии продолжают проверяться в фоне.
- После завершения подбора выбирается полный результат с наименьшей задержкой. Оценка превью используется при равной задержке.
- Применение проверенного результата больше не запускает повторные тесты и двухминутное испытание.
- Ручной выбор использует сохранённый полный результат для той же сети и сервиса, если ему менее трёх дней. Старые, неполные и исключённые результаты повторно использовать нельзя.
- Смена сети, остановка и новая команда отменяют применение устаревших результатов. Второй сервис не перезапускается. Уже открытые соединения сохраняются: если резервный слот занят ими, ускорение ожидает его освобождения.

APK подписан прежним постоянным сертификатом, установка поверх 0.10.0.
На телефоне проверить первое подключение до завершения подбора, последующий выбор меньшей задержки, ручной выбор без тестов, отмену и смену сети во время подбора. Сетевой результат на МТС/Tele2 требует проверки на устройстве.
