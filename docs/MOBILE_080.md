# DPI Pilot mobile 0.8.0

Смартфонная версия всегда предназначена для установленных официальных клиентов Instagram и YouTube. Выбор программ и выбор отдельной цели подбора удалены. Достаточно нажать основную кнопку VPN; пустой список приложений не допускается. Установленные клиенты определяются автоматически, остальные приложения в список VPN не добавляются.

## Тихий режим по умолчанию

Проверка выполняется при запуске/восстановлении службы, существенной смене физической сети и по кнопке сообщения о проблеме. После успешной проверки нет запланированных запросов к сервисам, фонового перебора ради оптимизации или регулярного наблюдения трафика. Счётчики обновляются при передаче данных; чтение показателей в открытом интерфейсе не создаёт сетевых запросов.

Автоматический стартовый поиск ограничен тремя кандидатами на сервис и короткими бюджетами ожидания; если подходящего варианта нет, остаётся прежний маршрут и программа ждёт нового события/запроса. Кнопки «YouTube не работает» / «Instagram не работает» запускают расширенный поиск. Периодический режим отдельно включается в настройках: раз в час после успеха, с интервалом 10 минут после неудачи. По умолчанию выключен.

## Независимые обработчики

Один Android VPN/TUN использует локальный SOCKS5 frontend на 127.0.0.1:1080. Frontend читает публичный HTTP Host или TLS ClientHello/SNI без расшифровки HTTPS. При числовом SOCKS-адресе он сохраняет и передаёт все прочитанные байты начального запроса. Для Instagram и YouTube используются отдельные native-процессы ByeDPI 17.3; у каждого сервиса есть основной и резервный слот.

При переключении одного сервиса новые соединения идут в его новый слот. Открытые соединения продолжаются на прежнем обработчике, другой сервис не перезапускается. Старый процесс освобождается после завершения его потоков; пока оба слота заняты открытыми потоками, запуск третьей команды откладывается. Полная остановка VPN или смена физической сети может прервать оба клиента.

Для нераспознанных доменов используется обычное соединение. В частности, ECH/отсутствующий SNI не позволяет надёжно приписать поток сервису. Трафик классифицируется по доменам, а не по содержимому экрана или аккаунту. UDP ASSOCIATE используется для DNS и прочих допустимых UDP-потоков выбранных клиентов, UDP/443 отбрасывается для перехода QUIC на TCP. Все слушающие сокеты привязаны к loopback.

## Испытание и резерв

Кандидат сначала проверяется отдельным тестовым процессом. Затем маршрут только данного сервиса переключается на резервный слот до двух минут. В тихом режиме активные пробы выполняются в начале и в конце испытания; между ними учитывается обмен новой генерации обработчика. Без спроса периодические пробы во время обычной работы не выполняются.

Идут ли реальные запросы, есть ли достаточные ответы и полезный поток, оценивается по счётчикам байтов/операций записи. Простой или буферизованное воспроизведение не считаются отказом. Счётчики не доказывают качество видео, доставку сообщений или работу аккаунта. При наблюдаемом отказе, смене сети/новом запросе пользователя и провале проверок выполняется откат. Кандидат не подтверждается до окончания пробного периода. Настройки активной команды сохраняются только после подтверждения; прерванное выключением испытание не становится стартовым вариантом.

Для каждого сервиса/профиля сети сохраняется история результатов и до пяти публично проверенных резервных команд. Текущий подтверждённый вариант имеет приоритет при следующем запуске. Профиль использует интерфейсы и DNS, не гарантирует различение всех Wi-Fi сетей с одинаковыми параметрами.

## Восстановление и профили

Настройка восстановления ранее включённого VPN действует после перезагрузки/замены APK и остановки системой, когда Android позволяет запуск. Требуется ранее выданное разрешение VPN. Ручное выключение и отзыв разрешения запоминаются; восстановление не должно бороться с другим выбранным пользователем VPN. Проверка состояния службы отдельным системным заданием не является сетевой проверкой YouTube.

Профиль экспортируется в небольшой JSON-файл. ТВ 0.6.2 экспортирует свою текущую YouTube-команду; телефон импортирует её как кандидата, сохраняя Instagram. Файл ограничен по размеру/схеме/версии движка и строгому списку параметров, показывается перед добавлением. Это пользовательский неподписанный файл, не доверенное обновление каталога; аккаунты и секреты в нём не передаются. Команда должна пройти обычное испытание.

## База и проверки выпуска

Подписанная база обновляется независимо раз в сутки и не запускает замену активных обработчиков. Добавлено отображение состояния известных источников. Еженедельное обнаружение новых источников создаёт очередь предложений на GitHub, не включает их команды в рабочую базу автоматически.

Проверки: SOCKS/UDP, границы доменов и фрагментированный TLS ClientHello; переключение/откат YouTube с сохранением открытых потоков Instagram и старого YouTube; трафик и правило тихого расписания; формат обмена; реальные независимые JNI-движки за production frontend; четыре ABI, manifest, подпись APK. Работа физического Android VPN и ограничения фонового запуска конкретной прошивки проверяются на устройстве.
