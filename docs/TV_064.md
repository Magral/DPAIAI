# DPI Pilot TV 0.6.4

## Проверки раз в три дня

Автоподбор включён по умолчанию, не чаще одного цикла за 72 часа для профиля сети. Время начала цикла сохраняется до отправки тестовых запросов. Перезагрузка, выход из сна, открытие интерфейса и восстановление процесса не обнуляют срок. Неудачный или незавершённый цикл также занимает свой интервал. Новая сеть имеет собственный срок. При отсутствии физической сети тесты не отправляются.

Кнопки «Проверить сейчас», «Найти самый быстрый вариант» и ручное применение выбранной стратегии допускают внеплановую проверку. Выключение переключателя автоподбора оставляет только проверки по требованию. Испытание фактически применённой замены до двух минут с короткими контрольными пробами и откатом — часть одного цикла, а не постоянное наблюдение. Самовосстановление VPN не отменяется.

## Постоянные исключения

Отказ полного теста, таймаут или неудачное испытание исключает стабильный ID команды в текущем профиле сети. Команда больше не участвует в автоматических и ручных тестах и скрывается из меню рабочих вариантов. Перезагрузка, обновление базы и новый номер той же команды не отменяют исключение. Частично успешная проверка не становится рабочей стратегией.

В меню рабочих стратегий есть «Сбросить исключения». Действие относится только к текущему профилю, требует явного нажатия и не запускает проверки само по себе. Можно затем нажать «Проверить сейчас». Старые записи только с отказами мигрируют как исключённые; исторически рабочие варианты сохраняются до нового реального отказа.

Профиль сети определяется существующей комбинацией интерфейса и DNS; он не является универсальным идентификатором провайдера или Wi-Fi SSID. При одинаковых параметрах разных сетей исключения могут совпасть — доступен явный сброс. Обрыв или смена физической сети во время теста не записываются как отказ команды.

## Меню и авторежим по задержке

Список рабочих вариантов отсортирован по возрастанию измеренной задержки HTTPS через стратегию; варианты без измерения расположены в конце. Это длительность проверочных HTTPS-запросов к узлам YouTube, не ICMP-пинг и не скорость видеопотока. Старый рейтинг по времени обмена больше не определяет сортировку.

Разовый цикл последовательно тестирует все доступные неисключённые команды через отдельный scout-процесс, не закрывая активный туннель. Большая база может проверяться долго; ход виден в приложении, успешные результаты и исключения сохраняются сразу. Новая ручная команда/смена сети прерывает устаревший подбор; незавершённые запросы не исключаются. Наименьшая задержка выбирается среди успешных проверок цикла, включая текущую стратегию; при равенстве текущая сохраняется. Если текущая самая быстрая, VPN не пересоздаётся. Если нужен переход, возможен переподключение видео и запускается ограниченное испытание с резервом.

Открытие меню, сортировка и обновление подписанной базы сами не создают сетевых проб. Постоянного опроса YouTube или оптимизации между циклами нет. Ручной выбор сохраняется для старта; следующий автоматический цикл может выбрать более быстрый вариант. Для фиксации ручного выбора выключите автоподбор.
