# DPI Pilot mobile 0.9.0

Телефон всегда обслуживает Instagram и YouTube одновременно. Выбора списка приложений нет; меню стратегии раздельно для каждого сервиса.

## Частота и фон
Автоподбор включён по умолчанию, один цикл за 72 часа на сервис и профиль сети. Начало цикла сохраняется до тестов: перезапуск устройства, открытие окна, смена состояния службы и неудачный цикл не обнуляют срок. Для новой сети срок отдельный. Переключатель отключает автоподбор, оставляя запросы по кнопке. Локальное восстановление обработчика не обходит сетевое расписание. Испытание фактической замены до двух минут — часть цикла, не постоянное наблюдение.

Подбор идёт в VPN-службе, экран можно закрывать. «Остановить текущий подбор» отменяет ожидающие запросы, откатывает незавершённое испытание и переносит следующий автоматический цикл на 72 часа. Прежние рабочие маршруты сохраняются; ручной запуск остаётся доступным.

## Полный отбор и история
Instagram: три TLS-узла, два раунда — 6/6. HTTP-ограничения анонимного Instagram не проверяются в обязательном транспортном тесте. YouTube: generate_204, JPEG-превью, TLS к redirector и API, два раунда — 8/8. В отличие от старого мобильного критерия 4/4, теперь нужны также оба прежних дополнительных узла. Частичная доступность больше не считается рабочим результатом.

История сохраняет полный последний результат, медианную задержку узлов и исключения. Рабочее меню сортируется по возрастанию задержки HTTPS. Старые положительные счётчики без полного результата требуют новой проверки. Минимум выбирается только среди успешных проб текущего цикла; при равенстве сохраняется текущий маршрут. При ручном применении выбранная команда предварительно проверяется заново.

Неудачная команда исключается отдельно для сервиса и профиля сети, не удаляется из общей базы и может работать на другой сети. Исключения больше не вытесняются после восьми записей и не истекают через 30 минут. Сброс исключений разрешает повторный тест, но не делает старую неудачную запись рабочей. Профиль сети использует существующие интерфейсы/DNS; это не универсальный идентификатор Wi-Fi или провайдера.

## Ускорение
Параллельно проверяются максимум четыре разных узла одной команды, без параллельных native-движков кандидатов. После первого отказа отменяются оставшиеся запросы раунда, второй раунд не запускается. Для полной успешной оценки нужны все узлы обоих раундов. Число успехов в частично отменённой проверке не означает полный результат.

Отмена, новое ручное действие и смена сети закрывают сокеты/пробный процесс и не исключают незавершённый вариант. Ограничены сроки DNS/SOCKS/TLS/HTTP. Удалены HTTP-ожидания Instagram, которые не могли изменить транспортный вердикт, повторное чтение списка исключений для каждой команды и частые тяжёлые публикации истории в UI.

Один цикл большой базы всё ещё может быть длительным: это сравнение множества команд, а не мгновенный тест скорости. Меняется только маршрут проверяемого сервиса; другой сохраняется. Два native-слота на сервис обеспечивают испытание и откат с завершением старых соединений. Обновление базы само не переключает рабочий маршрут.

## Проверки выпуска
Регрессионные тесты: строгая оценка всех узлов, частичный быстрый кандидат, постоянные исключения сверх старого лимита, разделение сети/сервиса, сброс без восстановления успеха, трёхдневное расписание, ограничение параллелизма и отмена ожидающих потоков после первого отказа. Сохраняются проверки реального JNI/маршрутизатора и постоянного сертификата APK.

Успешные публичные пробы не гарантируют доступ к аккаунту, ленте, Reels и каждому ролику. Реальную работу проверяет владелец на устройстве.
