# DPI Pilot 0.12.3

Исправлен отбор YouTube: одного TLS-соединения с API больше недостаточно. Требуется содержательный ответ player JSON в двух новых соединениях. UNPLAYABLE/LOGIN_REQUIRED подтверждают только транспорт API, а не доступ к видео или аккаунту. Старые результаты без новой проверки сохраняются в истории, но не считаются новым полным доказательством. Команды, активный маршрут и расписание 72 часа сохранены. Недоступный публичный образец/HTTP 403/429/ошибка сервера не приводит к постоянному исключению стратегии. Диагностика показывает публичную причину отказа API без URL и снимок настроек. Это исправление ложноположительного отбора; восстановление видео в конкретной сети требует проверки на устройстве, обход блокировки не гарантируется.

YouTube: 13 адресов, один видимый проход; два обмена API внутри одного пункта. Instagram: прежние 6/6 и отдельная стратегия. Устанавливайте APK поверх предыдущей версии.
