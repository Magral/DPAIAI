# DPI Pilot 0.13.1 — WARP: восстановление и проверка видео

Бесплатный WARP остаётся отдельным ручным режимом для смартфона. Добавлена кнопка «Проверить видео через работающий WARP»: проверяет публичный API проигрывателя и доступные фрагменты видео/звука через сеть WARP. DNS и сокеты проверки явно привязаны к VPN: при его потере тест не уходит в обычный интернет. Отмена, переподключение и выключение делают старый результат недействительным. Тест выполняется только по требованию, без фонового просмотра роликов и изменения стратегий.

Для проверки в VPN включён сам DPI Pilot вместе с YouTube и Instagram: его собственные запросы диагностики/обновлений тоже используют WARP. Все другие приложения исключены; если YouTube/Instagram не установлены, запуск отклоняется. Рукопожатие и счётчики отдельно от загрузки медиа. Публичный образец может не выдаваться из-за входа, подписи или изменений YouTube: это «не проверено», а не успех и не основание удалять стратегии.

Время ожидания рукопожатия увеличено до 12 секунд на вариант с общим бюджетом прохода 2 минуты. Порты/режимы чередуются, последняя удачная комбинация первая. После неудачного прохода повтор через 30 секунд, затем 2 минуты, далее 10 минут. Остановка отменяет ожидание. Рабочее подключение не переключается из-за простоя. Ключ сохраняется при сетевых сбоях; в статусе указаны безопасные категории ошибок без ключей и конфигурации.

Первый запуск: выключить DPI Pilot → «Режим подключения» → выбрать WARP → создать собственное подключение Cloudflare либо импортировать свой .conf. При блокировке регистрации можно один раз создать подключение через уже работающий Nova WARP, включив DPI Pilot в его туннель. Затем отключить Nova и включить DPI Pilot. Сохранённый профиль 0.13.0 переиспользуется.

Android7+ для WARP. Постоянная подпись, установка поверх старой версии. Локальный обход сохранён. MASQUE и автоматическое переключение с локальных стратегий в этот выпуск не входят. ТВ/Windows не перевыпускаются: сначала требуется проверка самостоятельного WARP на телефоне — меню, видео, Shorts, Instagram. Автоматические тесты и сборка не заменяют эту проверку.
