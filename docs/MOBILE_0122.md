# DPI Pilot 0.12.2

Диагностический выпуск: ручная проверка меню и видеодоставки YouTube. Отдельно показаны DNS, содержательный ответ API, карта CDN и загрузка настоящего медиадиапазона с объёмом/временем/скоростью. Системный маршрут и локальный DPI Pilot проверяются отдельно. Тест не меняет VPN/DNS/стратегии/исключения и не запускается в фоне. Закрытый/истёкший образец не считается отказом всех стратегий. 6/6 означает доступность узлов, а не гарантию видео. Для установления причины в конкретной сети сравните отчёты обычной сети и платного VPN. Диагностика не обещает устранить блокировку провайдера; нового внешнего туннеля нет.

Откройте кнопку «Диагностика меню и видео YouTube» на главном экране. Для сравнения сначала остановите DPI Pilot и сохраните системный тест обычной сети; затем включите платный VPN, покрывающий это приложение, и повторите. Сохраните два отдельных отчёта. Набор стратегий, DNS и расписание автоподбора не менялись. Установите поверх прежнего APK, постоянный сертификат сохранён.
